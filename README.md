# Tycoon Argentina — Descargas

<img src="icono.png" width="128" align="right" alt="Ícono de Tycoon Argentina">

Simulador de negocios pixel art para Android: arrancás con un puestito callejero
y crecés hasta un conglomerado empresarial. Todo es ficticio y humorístico.

## Descargar

Andá a **[Releases](../../releases/latest)** y bajá el archivo `.apk` de la última versión.

## Instalar en el celular

1. Abrí el `.apk` descargado desde el celular.
2. Si Android lo pide, permití "Instalar apps desconocidas" para el navegador o el gestor de archivos.
3. Tocá **Instalar** y abrí *Tycoon Argentina*.

Requisitos: Android 7 o superior. No pide internet ni datos personales (sólo vibración).
El progreso se guarda en el teléfono.

> Versión de prueba (firmada en modo debug). Para actualizar, instalá la nueva encima
> de la anterior: el progreso se conserva.
